UPTURN BAY — a travel poster for a place that isn't there. A pure-Python program (standard library only, no network, no assets) draws a 1024×1024 dusk poster of a fishing town where the waterfall falls UP: the sea pours skyward off the cliff, townsfolk fish the rising water from their rooftops, a child in a yellow raincoat points up laughing, and a pinned note from Mara, 9, talks to the judge.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024×1024 PNG, about 32 KB). Deterministic: repeated runs produce byte-identical output.
